# Projects board

## Prompt

High-fidelity UI design mockup of a personal life-OS app called Eudaimonia, 'Matte & Torn' design language: a matte textured black background (#0B0B0C) with very subtle static grain, under which live light torn-paper sheets — sections appear where the black skin is torn open, each section on its own soft paper tint (mint, sky blue, blush, butter) with slightly ragged dark-fringed edges, flat (no blur) like real paper; UI buttons, nav bubbles and interactive chips are dark frosted glass (subtle white overlay, 1px translucent border, soft backdrop blur, rounded). Two-accent system: vivid teal (#2DD4BF) marks things the user acts on; deep plum purple (#B872F2) marks AI-agent elements. Fixed status colors: green #27963C on paper / #3FB950 on glass (alive/ok), red #F85149 (dead/error), amber #D29922 (paused/pending). Text on paper is warm dark ink (#2B2926) — print-like, high contrast. Clean IBM Plex-style sans-serif and serif on paper, small monospaced muted captions. Minimal, modern, premium productivity-app aesthetic, vector-crisp, high detail, professional Dribbble shot. Short legible labels only; generous whitespace; no clutter, no light theme, no lorem ipsum walls. Portrait smartphone app screen, tall 9:19.5 aspect ratio. Navigation: a small cluster of floating dark-glass bubble buttons at the bottom-right corner (icon-only, active bubble ringed teal) instead of any fixed bottom bar; no bubbles at all on the wake screen. SCREEN: a three-column kanban-style board with glass columns headed ACTIVE, PARKED, DONE. Project cards with a name ('Market Momentum', 'Kerdos'), a small status dot, task counts, and a tiny muted-gray board-health sparkline (data charts never use accent colors). Column '+' buttons are small teal outline circles (plum is never decorative). Status derives from evidence: the DONE column shows green dots, no amber flags anywhere, no percentages colored in accent hues; the PARKED column's cards render deliberately muted and dimmer with 'parked since Aug' in small mono. Neutral rows, teal only on interactive elements — no alarm colors.

# Agents screen

## Prompt

High-fidelity UI design mockup of a personal life-OS app called Eudaimonia, 'Matte & Torn' design language: a matte textured black background (#0B0B0C) with very subtle static grain, under which live light torn-paper sheets — sections appear where the black skin is torn open, each section on its own soft paper tint (mint, sky blue, blush, butter) with slightly ragged dark-fringed edges, flat (no blur) like real paper; UI buttons, nav bubbles and interactive chips are dark frosted glass (subtle white overlay, 1px translucent border, soft backdrop blur, rounded). Two-accent system: vivid teal (#2DD4BF) marks things the user acts on; deep plum purple (#B872F2) marks AI-agent elements. Fixed status colors: green #27963C on paper / #3FB950 on glass (alive/ok), red #F85149 (dead/error), amber #D29922 (paused/pending). Text on paper is warm dark ink (#2B2926) — print-like, high contrast. Clean IBM Plex-style sans-serif and serif on paper, small monospaced muted captions. Minimal, modern, premium productivity-app aesthetic, vector-crisp, high detail, professional Dribbble shot. Short legible labels only; generous whitespace; no clutter, no light theme, no lorem ipsum walls. Portrait smartphone app screen, tall 9:19.5 aspect ratio. Navigation: a small cluster of floating dark-glass bubble buttons at the bottom-right corner (icon-only, active bubble ringed teal) instead of any fixed bottom bar; no bubbles at all on the wake screen. SCREEN: an agent fleet monitor, strictly read-only — no action buttons anywhere. One glass row per AI agent profile: agent name, a status dot (one green, one red, two amber, rest muted), a mono last-run time, and a small 'invocations this week' count. The red row is expanded, showing a muted remediation hint as PLAIN TEXT ONLY: 'digest dead since Sep 22 — free-model expiry · repoint model pin' — no button, no 'fix now' affordance. Below, a section header 'MULTICA TASKS' with two subdued task rows. Diagnostic, calm, color-coded by state — never by accent.

# Agent chat console

## Prompt

High-fidelity UI design mockup of a personal life-OS app called Eudaimonia, 'Matte & Torn' design language: a matte textured black background (#0B0B0C) with very subtle static grain, under which live light torn-paper sheets — sections appear where the black skin is torn open, each section on its own soft paper tint (mint, sky blue, blush, butter) with slightly ragged dark-fringed edges, flat (no blur) like real paper; UI buttons, nav bubbles and interactive chips are dark frosted glass (subtle white overlay, 1px translucent border, soft backdrop blur, rounded). Two-accent system: vivid teal (#2DD4BF) marks things the user acts on; deep plum purple (#B872F2) marks AI-agent elements. Fixed status colors: green #27963C on paper / #3FB950 on glass (alive/ok), red #F85149 (dead/error), amber #D29922 (paused/pending). Text on paper is warm dark ink (#2B2926) — print-like, high contrast. Clean IBM Plex-style sans-serif and serif on paper, small monospaced muted captions. Minimal, modern, premium productivity-app aesthetic, vector-crisp, high detail, professional Dribbble shot. Short legible labels only; generous whitespace; no clutter, no light theme, no lorem ipsum walls. Portrait smartphone app screen, tall 9:19.5 aspect ratio. Navigation: a small cluster of floating dark-glass bubble buttons at the bottom-right corner (icon-only, active bubble ringed teal) instead of any fixed bottom bar; no bubbles at all on the wake screen. SCREEN: a chat thread with an AI agent. Top: an attachment chip '▸ attached: week 41 export' with a plum outline. The thread: user messages as right-aligned teal-tinted glass bubbles, agent replies as left-aligned glass bubbles with a small plum dot avatar and a plum left border; one agent message carries a tiny '~est' marker and a muted provenance footer line. Bottom: an input bar with a plum send icon. Chat rendered as provenance: plum always means the agent spoke.
